# Repoblacion de tablas fuente — 1M registros base

**Fecha:** 2026-05-07
**Herramienta:** `provisioners/mariadb/poblar_historico.py`
**Motivo:** El seed original de 50K registros por quarter era insuficiente
para pruebas representativas. Se escala a 1M base para reducir el error
estadistico de ±0.22pp a ±0.05pp y hacer el ETL mas significativo.

---

## Comando ejecutado

```bash
cd provisioners/mariadb
python3 poblar_historico.py \
    --rows 1000000 \
    --truncate \
    --chunk 500 \
    --socket /run/mysqld/mysqld.sock
```

**Tiempo total:** 143 segundos (~2.4 minutos)

### Anomalias detectadas en el verificador

**A-SEED-001 — `cMenu = numero telefono = 0.0%` (target 1.2%)**

El verificador usa `cMenu REGEXP '^[0-9]+$'` pero ninguna fila la cumple
en Q01_25. El generador tiene el path de `__CMENU_ERROR__` en el codigo
pero el perfil `q01_2025.py` no lo incluye con probabilidad > 0. Esta
condicion si existe en Q02_25 y Q03_25 donde el perfil la define.
No es un bug funcional del ETL — `fn_normalizar_menu` procesa correctamente
los menus que llegan de la fuente real de produccion.

**A-SEED-002 — `CLIENTE_COLGO = 39%` en Q01_25/Q01_26 (target 27.4%)**

Los quarters sin perfil de VDN detallado para todos los menus caen al
pool default de `gen_vdn`, que tiene 30% de probabilidad para `cliente_colgo`.
Q02_25 tiene perfiles VDN mas detallados y da 28.7% (dentro del rango).
No afecta el ETL: `fn_normalizar_centro('cliente_colgo')` retorna
`CLIENTE_COLGO` correctamente en todos los casos.

## Nota sobre sp_etl_maestro

`sp_etl_maestro` calcula el quarter actual automaticamente con `CURDATE()`.
En Mayo 2026 procesa Q02_26 (tbl_historico_t2_2026). Para procesar quarters
historicos en pruebas, usar directamente:

```sql
CALL sp_etl_base_detalle('Q01_25', '2025-01-01', '2025-03-31',
     'tbl_historico_t1_2025', NULL);
CALL sp_etl_base_clientes('Q01_25', '2025-01-01', '2025-03-31',
     'tbl_historico_t1_2025', NULL);
```

En Fase 3 (backfill), `sp_etl_historico(year, quarter)` encapsula esta logica
correctamente para cada quarter historico.
